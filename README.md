# 🧩 Отображение новых эмодзи для Windows 10

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.2.1-blue.svg)](https://github.com/Vova-iz-Tambova/windows-10-emoji-square-fixer)

**Расширение/юзерскрипт для браузера, который заменяет отсутствующие в Windows 10 современные эмодзи на актуальные картинки Twemoji 17.**

Вместо пустых квадратиков `▯` вы будете видеть новые эмодзи.

---

## 🚨 Проблема

Windows 10 **не поддерживает эмодзи, выпущенные после 2019 года** (Unicode 13+), включая свежие эмодзи Emoji 16.0 (2024).

Когда вы встречаете в интернете такие символы, как 🫶, 🪴, 🧋, вместо них отображается пустой прямоугольник `▯` или `�`.

**Этот инструмент решает проблему на уровне браузера.**

## ❌ Что НЕ трогается

- **Старые эмодзи** (😀😂❤️😍👍🔥🦌) — и так отображаются
- **Символы письменности** (например, `｡`) — не являются эмодзи
- **Поля ввода и редакторы** (`contentEditable`, `textarea`) — чтобы не ломать набор текста
- **Содержимое `script`/`style`/`iframe`** — где замены не нужны

- **Обновление до Twemoji 17.0.3** — все ассеты Emoji 16.0/17.0 доступны
- **Поддержка флагов стран** 🇷🇺🇺🇸🇩🇪 — все 258 флагов рендерятся через Twemoji
- **Корректная обработка составных эмодзи** — ZWJ-последовательности (👨‍👩‍👧‍👦, 🧑‍🚀), все тона кожи, парные тоны bunny ears, таблица `fe0f`-имён файлов (❤️‍🔥 и др.)
- **Проверенная механика 1.1.3 без изменений** — один самодостаточный файл `content.js`, замена через `<span class="emoji-fixed">` + `innerHTML`, полный пересканирование при каждой мутации — максимальная совместимость с сайтами (включая GitHub), где контент перечитывается


## 📁 Структура проекта

| Файл | Назначение |
|------|-----------|
| [`manifest.json`](manifest.json) | Манифест расширения (MV3) |
| [`content.js`](content.js) | Всё в одном файле: движок (сканирование DOM, замена, `MutationObserver`) + таблица эмодзи Emoji 12.0–17.0 и флагов |

> Расширение и юзерскрипт используют **только** `content.js` — он полностью самодостаточный.

## 📥 Установка

### Способ 1: Как расширение (рекомендуется)

#### Chrome / Edge / Brave

1. Скачайте или склонируйте этот репозиторий
2. Откройте `chrome://extensions/`
3. Включите **«Режим разработчика»** (Developer mode)
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked)
5. Выберите папку с файлом `manifest.json`

#### Firefox

1. Скачайте или склонируйте этот репозиторий
2. Откройте `about:debugging`
3. Нажмите **«Этот Firefox»** → **«Загрузить временное дополнение»**
4. Выберите файл `manifest.json`

### Способ 2: Как юзерскрипт (Tampermonkey)

1. Установите расширение **Tampermonkey**
2. Нажмите на иконку Tampermonkey → **Создать новый скрипт**
3. Скопируйте содержимое файла `content.js` (в нём уже есть заголовок `==UserScript==`) и вставьте вместо стандартного кода
4. Нажмите `Ctrl + S` для сохранения

> 💡 Юзерскрипт работает и на сайтах со строгой CSP (GitHub, VK и т.п.): ассеты загружаются через `GM_xmlhttpRequest` и подставляются как `data:` URI. При первой установке Tampermonkey запросит разрешение на доступ к `cdn.jsdelivr.net` — подтвердите его.

| Что НЕ поддерживается | Причина |
|----------------------|---------|
| Символы письменности | Не являются эмодзи |
| Системные цвета темы | Браузер не даёт доступа |
| Эмодзи Unicode 18+ | Ещё не вышли в Twemoji-ассетах этой версии |

## 🛠 Технические детали

| Параметр | Значение |
|----------|----------|
| Поддерживаемые эмодзи | Emoji 12.0–17.0 (1150 последовательностей) |
| Флаги стран | 258 комбинаций Regional Indicators (U+1F1E6–U+1F1FF) |
| Источник картинок | Twemoji 17.0.3 (jdecked/twemoji) |
