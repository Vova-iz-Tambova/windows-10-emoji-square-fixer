# 🧩 Отображение новых эмодзи для Windows 10

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Расширение/юзерскрипт для браузера, который заменяет отсутствующие в Windows 10 современные эмодзи на актуальные картинки Twemoji.**

Вместо пустых квадратиков `▯` вы будете видеть новые эмодзи.

---

## 🚨 Проблема

Windows 10 **не поддерживает эмодзи, выпущенные после 2018 года** (Unicode 13+).

Когда вы встречаете в интернете такие символы, как 🫶, 🪴, 🧋, 🤌, 🫰, 🫵, вместо них отображается пустой прямоугольник `▯` или `�`.

**Этот инструмент решает проблему на уровне браузера.**

---

## ✅ Что поддерживается

Все современные эмодзи (Unicode 13-16):

| Эмодзи | Название |
|--------|----------|
| 🫶 | Сердце-руки |
| 🪴 | Растение в горшке |
| 🧋 | Бабл-ти |
| 🤌 | Пальцы щепоткой |
| 🫰 | Пальцы сердцем |
| 🫵 | Палец на зрителя |
| 🩷 | Розовое сердце |
| ❔ | Вопросительный знак |
| 🈺 | Японский "открыто" |
| 🚺 | Женский символ |
| 💟 | Сердце с точкой |
| 🪟 | Окно Windows |
| 🤡 | Клоун |

И другие современные эмодзи.

---

## ❌ Что НЕ поддерживается

**Флаги стран** (🇷🇺 🇺🇸 🇩🇪 🇫🇷 и другие).

**Техническая причина:** Windows 10 заменяет символы флагов на символы-заменители (`�`) ещё до того, как скрипт может их обработать. Восстановить исходные символы из `�` невозможно.

## 📥 Установка

### Способ 1: Как расширение (рекомендуется)

#### Chrome / Edge / Brave

1. Скачайте или склонируйте этот репозиторий
2. Откройте `chrome://extensions/`
3. Включите **«Режим разработчика»** (Developer mode)
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked)
5. Выберите папку с файлом `manifest.json`

#### Firefox

1. Скачайте или склонируйте этот репозиторий
2. Откройте `about:debugging`
3. Нажмите **«Этот Firefox»** → **«Загрузить временное дополнение»**
4. Выберите файл `manifest.json`

### Способ 2: Как юзерскрипт (Tampermonkey)

1. Установите расширение **Tampermonkey**:
   - [Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   - [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/)
   - [Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)

2. Нажмите на иконку Tampermonkey → **Создать новый скрипт**

3. Скопируйте содержимое файла `content.js` и вставьте вместо стандартного кода

4. Нажмите `Ctrl + S` для сохранения

**Прямая ссылка для установки (нажмите после установки Tampermonkey):**

```
https://github.com/Vova-iz-Tambova/windows-10-emoji-square-fixer/raw/main/content.js
```

## 🎨 Ограничения

Инструмент использует готовые цветные изображения из библиотеки **Twemoji** (Twitter Emoji).

**❌ Что НЕ поддерживается:**
- Использование системных цветов вашей темы Windows
- Автоматическая подстройка под акцентный цвет
- Флаги стран (см. раздел выше)

**Почему?** Браузеры не предоставляют доступ к системным цветам Windows из соображений безопасности.
