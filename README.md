# 🧩 Отображение новых эмодзи для Windows 10

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.1.2-blue.svg)](https://github.com/Vova-iz-Tambova/windows-10-emoji-square-fixer)

**Расширение/юзерскрипт для браузера, который заменяет отсутствующие в Windows 10 современные эмодзи на актуальные картинки Twemoji 15.1.**

Вместо пустых квадратиков `▯` вы будете видеть новые эмодзи.

---

## 🚨 Проблема

Windows 10 **не поддерживает эмодзи, выпущенные после 2018 года** (Unicode 13+).

Когда вы встречаете в интернете такие символы, как 🫶, 🪴, 🧋, вместо них отображается пустой прямоугольник `▯` или `�`.

**Этот инструмент решает проблему на уровне браузера.**

---

## ✅ Что поддерживается

**Только новые эмодзи** (Unicode 13-15.1), которые Windows 10 не поддерживает:

| Эмодзи | Название |
|--------|----------|
| 🫶 | Сердце-руки |
| 🪴 | Растение в горшке |
| 🧋 | Бабл-ти |

| 🫵 | Палец на зрителя |

| ❔ | Вопросительный знак |
| 🈺 | Японский "открыто" |
| 🚺 | Женский символ |
| 💟 | Сердце с точкой |
| 🪟 | Окно Windows |
| 🤡 | Клоун |
| 🛖 | Хижина |
| 🛻 | Пикап |
| 🛼 | Роликовый конёк |
| 🫠 | Тающее лицо |

И другие современные эмодзи.

---

## ❌ Что НЕ трогается

- **Старые эмодзи** (😀😂❤️😍👍🔥) — и так отображаются
- **Флаги стран** (🇷🇺🇺🇸🇩🇪) — не поддерживаются Windows
- **Редкие/новейшие эмодзи** (U+1FAE9–U+1FAF0) — практически не встречаются в интернете

## 📥 Установка

### Способ 1: Как расширение (рекомендуется)

#### Chrome / Edge / Brave

1. Скачайте или склонируйте этот репозиторий
2. Откройте `chrome://extensions/`
3. Включите **«Режим разработчика»** (Developer mode)
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked)
5. Выберите папку с файлом `manifest.json`

#### Firefox

1. Скачайте или склонируйте этот репозиторий
2. Откройте `about:debugging`
3. Нажмите **«Этот Firefox»** → **«Загрузить временное дополнение»**
4. Выберите файл `manifest.json`

### Способ 2: Как юзерскрипт (Tampermonkey)

1. Установите расширение **Tampermonkey**
2. Нажмите на иконку Tampermonkey → **Создать новый скрипт**
3. Скопируйте содержимое файла `content.js` и вставьте вместо стандартного кода
4. Нажмите `Ctrl + S` для сохранения

**Прямая ссылка для установки:**

```
https://github.com/Vova-iz-Tambova/windows-10-emoji-square-fixer/raw/main/content.js
```

> ⚠️ **Важно:** Юзерскрипт может не работать на сайтах со строгой политикой безопасности (CSP), таких как GitHub и Яндекс. Для этих сайтов используйте расширение.

## 🎨 Ограничения

| Что НЕ поддерживается | Причина |
|----------------------|---------|
| Флаги стран | Windows заменяет их на символы-заменители |
| Старые эмодзи | Они и так работают, не трогаем |
| Редкие новейшие эмодзи | Отсутствуют в Twemoji 15.1 |
| Системные цвета темы | Браузер не даёт доступа |
